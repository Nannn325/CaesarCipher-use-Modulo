Penjelasan Modulo Dalam Caesar Cipher

1. Mengapa Menggunakan Modulo 26?

Alfabet bahasa Inggris memiliki 26 huruf (A sampai Z). Ketika pergeseran posisi huruf melebihi huruf Z, operator modulo mod 26 berfungsi sebagai siklus siklik yang memutar kembali pergeseran ke awal alfabet (A).

2. Contoh Kasus Enkripsi (Z + 3):

Huruf 'Z' memiliki indeks 25. Jika digeser sebesar 3:
(25 + 3) mod 26 = 28 mod 26 = 2
Nilai 2 dipetakan kembali ke huruf 'C'.

3. Contoh Kasus Dekripsi Nilai Negatif:

Jika dekripsi menghasilkan angka negatif, sifat aritmatika modulo Python secara otomatis mengatasinya.
Contoh: (0 - 3) mod 26 = -3 mod 26 = 23 (Huruf 'X').
